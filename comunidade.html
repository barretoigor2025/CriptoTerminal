Falta configurar o Firebase. Abra este arquivo e cole as chaves do seu projeto no bloco FIREBASE_CONFIG no topo do <script>. Passo a passo abaixo.
Ligar o Firebase (grátis, uma vez só):
1. Crie um projeto em console.firebase.google.com
2. Em Build → Firestore Database → Criar banco (modo de teste).
3. Em Config. do projeto → Seus apps → Web, copie o firebaseConfig.
4. Cole no bloco FIREBASE_CONFIG no topo do script e salve.
