Falta configurar o Firebase. Abra este arquivo e cole as chaves do seu projeto no bloco FIREBASE_CONFIG no topo do <script>. Passo a passo no rodapé desta tela.
Como ligar o Firebase (grátis, uma vez só):
1. Crie um projeto em console.firebase.google.com
2. Em Build → Firestore Database, clique Criar banco (modo de teste).
3. Em Configurações do projeto → Seus apps → Web, registre um app e copie o objeto firebaseConfig.
4. Cole no bloco FIREBASE_CONFIG no topo do script deste arquivo e salve.
